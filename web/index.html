Everything it does

One toolkit for the whole trip

Search, watch, score, advise, book. Each capability is an independent Python module you can call directly, from the CLI, or through the MCP server.

🔎

Real-time flight search

Live fares through the Duffel API plus deep links for Google Flights, Avianca, Iberia, KLM, Air France, Kayak and Skyscanner. flight_scraper.py

📈

Price monitoring

Watch unlimited routes, keep a full price history, and compute medians and trends per route. flight_monitor.py

🔔

Smart alerts

Fires on target price, below-median deals and sharp drops. Console or email, with de-duplicated alert history. alerts.py

🧠

Recommendation engine

Every fare scored 0–100 — 40% price, 30% duration, 20% stops, 10% your preferences — with written reasons. recommendations.py

📅

Flexible-date sweeps

Every outbound/return pair and both baggage modes on Google Flights, keeping all carrier combinations. google_flights_monitor.py

📉

365-day price baseline

Scans a year of recorded fares for the route, then turns a live price into a verdict: buy now, good, fair, wait or high. price_baseline.py

💺

Seat selection, end to end

FlightAware and SeatMaps for the verified workflow, cross-checked on SeatGuru, aeroLOPA, ExpertFlyer and Flightradar24 — plus when to actually claim the seat. seat_advisor.py

💳

Loyalty & points

Track cards, balances and tiers, and estimate points earned on any fare before you buy. loyalty_cards.py

🧳

Passenger profiles

Store travellers, passports and frequent-flyer numbers so a booking can be filled in one pass. passenger_profiles.py

📊

Fare history & dashboard

Alert-safe history store plus a rendered fare dashboard image for reports and digests. fare_history.py · dashboard.py

The part everyone asks for

Let the agent buy the ticket

SkyBuddy does not scrape a checkout behind your back. It builds a booking intent: a structured, auditable object carrying the exact flight link, the passengers, the price you agreed to, and the checks that must pass before money moves.

  1. 0
    auto_book_if_dealOptional: the 365-day baseline decides the fare is buy-worthy and creates the intent for you.
  2. 1
    prepare_bookingPins the chosen offer, its booking URL and price into a saved intent.
  3. 2
    Human confirmationNothing executes until you approve the intent by its id.
  4. 3
    confirm_bookingRe-validates the price ceiling, then releases the agent playbook.
  5. 4
    Agent executesYour agent opens the link, fills passenger data, checks the seat map on long-haul, and stops at payment for the final human OK.
Safe by default: dry-run mode, a hard price ceiling, and an explicit stop before any payment step.
booking_agent.py 
from booking_agent import get_booking_agent

booking = get_booking_agent()

intent = booking.prepare_booking(
    booking_url="https://www.iberia.com/…",
    airline="Iberia",
    origin="BIO", destination="BOG",
    outbound_date="2026-12-04",
    return_date="2027-01-08",
    price=684.0, currency="EUR",
    passengers=["harold"],
    max_price=700.0,          # hard ceiling
)

# → {"intent_id": "bk_7f3a1c", "status": "awaiting_confirmation"}

booking.confirm_booking("bk_7f3a1c", approved_by="harold")

# → status "ready_to_execute" + a step-by-step
#   agent_playbook for the booking link

Quick start

Running in under a minute

Pure Python, one required dependency. Pick your entry point.

bash 
git clone https://github.com/HaroldMate1/SkyBuddy.git
cd SkyBuddy
pip install -r requirements.txt

# search a route (config or arguments)
python scripts/flight_scraper.py BIO BOG 2026-12-04 2027-01-08 EUR

# analyse collected fares
python scripts/analyze_prices.py

# monitor every watched route and raise alerts
python scripts/flight_monitor.py

# what does a good price look like? (365 days by default)
python scripts/price_baseline.py scan --origin BIO --destination BOG
python scripts/price_baseline.py evaluate --origin BIO --destination BOG --price 684
from agent_integration import create_agent

sky = create_agent()

result = sky.search_flights(
    origin="BIO", destination="BOG",
    outbound_date="2026-12-04",
    return_date="2027-01-08",
)

for rec in result["top_recommendations"]:
    print(rec["score"], rec["airline"], rec["price"], rec["booking_url"])

sky.add_route("Colombia Trip", "BIO", "BOG",
              "2026-12-04", "2027-01-08", target_price=650)
sky.check_all_routes()
# start the universal MCP server
python scripts/mcp_server.py claude

# claude_desktop_config.json / .mcp.json
{
  "mcpServers": {
    "skybuddy": {
      "command": "python",
      "args": ["scripts/mcp_server.py", "claude"],
      "cwd": "/path/to/SkyBuddy"
    }
  }
}
# 1 · create the intent from a flight link
python scripts/booking_agent.py prepare \
  --booking-url "https://www.iberia.com/…" \
  --airline Iberia --origin BIO --destination BOG \
  --outbound-date 2026-12-04 --return-date 2027-01-08 \
  --price 684 --currency EUR --passenger harold --max-price 700

# 2 · approve it explicitly
python scripts/booking_agent.py confirm --intent-id bk_7f3a1c --approved-by harold

# 3 · hand the playbook to your agent
python scripts/booking_agent.py playbook --intent-id bk_7f3a1c

# or let the year of history decide and create the intent itself
python scripts/price_baseline.py trigger --origin BIO --destination BOG   --outbound-date 2026-12-04 --price 684 --airline Iberia   --booking-url "https://www.iberia.com/…" --passenger harold

MCP surface

Tools any agent can call

The same set is exposed to Claude, Hermes, OpenClaw and any MCP client through mcp_server.py.

ToolWhat it does
search_flightsSearch a route and return fares plus the top scored recommendations.
add_routeWatch a route with an optional target price.
list_routesList watched routes with their latest prices.
check_all_routesRe-price every watched route and raise alerts.
get_alertsRecent alerts within a time window.
get_preferences / set_preferencesRead and update airline, time, cabin and stop preferences.
add_card / list_cardsManage credit cards used for points earning.
add_loyalty_programRecord a loyalty balance and tier.
estimate_earningsEstimate points earned on a given fare.
add_passenger / list_passengersManage traveller profiles for bookings.
prepare_bookingCreate a booking intent from a flight link, pending confirmation.
confirm_bookingApprove an intent after the price ceiling re-check.
get_booking_playbookReturn the step-by-step instructions the agent executes on the link.
list_bookings / cancel_bookingAudit trail for every intent, and cancellation before execution.
get_price_baselineScan the last 365 days of recorded fares: min, percentiles, median, trend, confidence.
evaluate_priceTurn a live fare into a buy verdict with reasons and its percentile.
auto_book_if_dealCreate the booking intent automatically when the fare beats its own history.
record_price_observationFeed one observed price into the baseline store.
get_seat_advisorySeat-map workflow, cross-check sites and the actions that assign the seat.
